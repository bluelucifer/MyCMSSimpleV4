## 주요 결정사항

### 에디터 선택
- **최초 계획**: TinyMCE (API 키 필요)
- **최종 결정**: Quill.js (무료, API 키 불필요)
- **선택 이유**: 간단한 구현, 무료 사용, 충분한 기능

### 데이터 저장 방식
- **데이터베이스**: 사용하지 않음
- **저장 방식**: JSON 파일 기반
- **장점**: 간단한 구현, 백업 용이, GitHub Pages와 호환

### 배포 방식
- **개발 환경**: 로컬에서 프론트엔드 + 백엔드 동시 실행
- **프로덕션**: 정적 HTML 파일을 GitHub Pages로 배포
