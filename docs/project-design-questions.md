## 4. 주요 기능
프로젝트에 포함하고 싶은 핵심 기능들은 무엇인가요?

1. 웹 wizwig 에디터로 문서를 작성
2. 작성된 문서를 html 코드로 변환
3. github pages로 배포
4. 작성된 문서 목록 및 미리보기
5. Pages로 배포 전 미리보기
